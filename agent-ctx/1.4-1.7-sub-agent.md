# Task 1.4-1.7 — Security Fixes (Payment Bypass, Feature Flags Auth, WebSocket CORS/Membership, Rate Limiting)

## Summary
Completed all 4 security fixes for the Daxelo-Kinrel NestJS backend. TypeScript compiles with 0 errors.

## Fix 1.4: Payment Verification Bypass
- **payments.service.ts**: Replaced `Record<string, any>` with typed DTO. Added Razorpay HMAC-SHA256 signature verification using `crypto.timingSafeEqual`. Production rejects unsigned requests; dev logs warning. Plan validated against `SubscriptionPlan` Prisma enum. Added `NotFoundException` on cancel for missing subscription.
- **payments.controller.ts**: Updated `@Body()` type from `Record<string, any>` to explicit DTO with `razorpayOrderId`, `razorpayPaymentId`, `razorpaySignature`, etc.

## Fix 1.5: Feature Flags Auth
- **feature-flags.controller.ts**: Removed class-level `@Public()`. Kept `@Public()` on GET endpoints. Added `@UseGuards(JwtAuthGuard)` + manual `role !== 'admin'` check (ForbiddenException) on POST.

## Fix 1.6a: KinrelGateway CORS + Membership

## Fix 1.6b: RealtimeGateway CORS + Membership
